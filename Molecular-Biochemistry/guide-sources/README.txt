Editable sources for the instructor-guide PDFs in the parent folder.

Each g_*.md is plain Markdown (tables, fenced code blocks and > callouts are
supported). Edit the text, then rebuild one PDF with:

    python3 build_guide.py g_docking.md "../Molecular Docking - Instructor Guide.pdf" \
            "Molecular Docking and Virtual Screening" "Molecular Docking.ipynb"

Arguments are: markdown source, output PDF, document title, notebook filename.
The author block, running footer and page styling are generated by the script,
so they stay consistent across all nine guides.

Requires: python3 with the "markdown" and "weasyprint" packages
    pip install markdown weasyprint

File pairing:
  g_foundations.md -> Foundations-unix-python-pdb
  g_databases.md   -> Databases - sequence -kinetics
  g_alignment.md   -> Sequence alignment
  g_forcefields.md -> Force Fields Energy Minimization
  g_solvation.md   -> Solvation ions md preparation
  g_md.md          -> Molecular Dynamics trajectories
  g_docking.md     -> Molecular Docking
  g_structpred.md  -> Structure Prediction
  g_peptide.md     -> Peptide Binder Design
