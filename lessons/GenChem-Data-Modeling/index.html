GenChem Data Modeling with Colab

A five-lesson module that uses Google Colab, Gemini, and Python to help students analyze and visualize data within the context of general chemistry.

Programming Skill: None
Primary Course: General Chemistry
Also for: Physical Chemistry, Analytical Chemistry
Format: Multi-Part Module

Estimated Time: 6-7 hours
Piloted with: Undergraduate - First/Second Year

Overview

This module introduces students to the use of Google Colab and Gemini for data analysis and visualization in a second-semester general chemistry course. The activities are designed to familiarize students with Python syntax and scientific libraries, develop effective AI prompting skills for chemistry problem solving, and deepen understanding of key chemical concepts.

The module consists of five lessons, each designed for a 75-minute class period. The activities are best implemented in a synchronous guided-inquiry setting, with teaching assistants and/or learning assistants available to support student learning. The first lesson serves as an introductory activity that familiarizes students with the Colab-Gemini workflow and is intended for use early in the semester. The remaining four lessons are independent, self-contained activities that can be implemented in any order to align with the course curriculum.

Scientific Learning Objectives

  • Interpret, analyze, and visualize data in chemical systems, including reaction kinetics, acid-base equilibria, and electrochemical cells.
  • Relate multiple representations of chemical information (data tables, graphs, equations, and models) to explain and predict chemical behavior.
  • Develop, apply, and evaluate mathematical models to explain chemical behavior.
  • Compare experimental results with theoretical predictions to draw evidence-based conclusions.

Cyberinfrastructure Learning Objectives

  • Access and open a notebook in Google Colab
  • Identify and use the key components of the Google Colab interface (code cells, text cells, run button).
  • Read and understand a Python script with comments.
  • Run a Python script and interpret its output.
  • Data Handling: Import and load a CSV file into a Pandas DataFrame.
  • Data Cleaning/Transformation: Calculate chemical quantities using mathematical models.
  • Data Visualization: Generate scatter plots using Python libraries (e.g., Pandas, Matplotlib, NumPy/SciPy).
  • Computational Analysis: Perform a linear fit to find the slope and intercept.
  • AI Literacy: Formulate effective and specific prompts to get the most out of an AI assistant.

Course Materials

Lesson 1: Introduction to Google Colab, Python, and Gemini

This lesson introduces students to Google Colab, Gemini, and Python as tools for analyzing and visualizing data related to the Ideal Gas Law .

View Notebook
75 minutes
Learning Objectives:
  • Analyze how volume changes with temperature from a data table.
  • Construct a volume vs. temperature graph and interpret the meaning of the slope and intercepts.
  • Derive the mathematical relationship from the graph and data.
  • Describe the relationship between volume and temperature and connect it to the Ideal Gas Law, PV = nRT.

Lesson 2: Reaction Kinetics of Organic Reactions

In this lesson, students use Google Colab, Gemini, and Python to read, analyze, and visualize kinetics data for organic reactions.

View Notebook
75 min
Learning Objectives:
  • Represent concentration data in tables and graphs.
  • Predict half-life for 1st- and 2nd-order reactions.
  • Model and compare 1st- and 2nd-order rate laws using Python.
  • Use models to identify reaction order by matching theoretical and experimental data.

Lesson 3: Reaction Kinetics of Drug Degradation

In this lesson, students use Google Colab, Gemini, and Python to read, analyze, and visualize kinetics data for drug degradation in aqueous solutions

View Notebook
75 min
Learning Objectives:
  • Interpret and compare rate constants across temperatures and pHs values.
  • Model k vs. T and lnk vs. 1/T at different pHs.
  • Relate slopes and y-intercept to activation energies Ea and frequency factor A.

Lesson 4: Titration Curves of Common Household Acids

In this lesson, students use Google Colab, Gemini, and Python to read, analyze, and visualize titration data of common household acids with a strong base.

View Notebook
75 min
Learning Objectives:
  • Identify key features of titration curves (buffer region, half-equivalence point, equivalence point) for weak acids.
  • Compare titration curves of polyprotic vs monoprotic acids, and match unknowns to reference curves.
  • Use curve shape and equivalence behavior to determine 𝑝𝐾𝑎 and identify an unknown acid.

Lesson 5: Impact of Concentrations on Voltaic Cell Potentials

In this lesson, students use Google Colab, Gemini, and Python to read, analyze, and visualize data for a voltaic cell under different conditions.

View Notebook
75 min
Learning Objectives:
  • Interpret how concentration changes influence cell potential.
  • Graph Ecell vs. concentrations, Q, or log⁡Q to identify trends.
  • Use Ecell vs. log⁡Q to determine n, Ecell standard, and K, and compare with theoretical predictions.

Instructor Notes

Additional context for instructors using this lesson:

• Lessons in this module can be implemented successfully in either a lecture or recitation setting as guided-inquiry activities.
• Students often need support navigating file systems, locating the correct data files on their computers, and uploading files to the appropriate directory within the Google Colab environment.
• Students complete these activities individually and submit both their complete guided-inquiry worksheet and Colab notebook for credit.
• Consider incorporating brief live-coding demonstrations and project your screen as you guide students through key steps and troubleshoot common issues.

Timing notes:
• Each lesson in the module is designed for a 75-minutes class period.
• Each lesson can be completed either before or after the relevant chemical concepts are discussed in lectures.

Common student questions:
• "Where are the plots?" • Gemini sometimes insert outputs or results into different sections of the Colab notebook, making it difficult for students to locate the requested code and plots.

Potential workarounds:
• Use more explicit prompts, such as: "Provide only the Python code needed to complete this task. Do not provide step-by-step explanations or summaries."
• Remind students to review the entire notebook for generated outputs.
