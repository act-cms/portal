Numerical Analysis of Cooling Curves to Determine the Molar Mass of an Unknown Compound

Students will interpret temperature-time cooling curves through interactive visualization and numerical analysis to determine the molar mass of an unknown solute

Programming Skill: Beginner
Primary Course: Physical Chemistry Lab
Also for: Physical Chemistry
Format: Multi-Part Module
Authors: Prof. Prajay Patel
Estimated Time: 3-4 hours
Piloted with: Undergraduate - Third/Fourth Year
Students Tested: 10
python pandas colligative properties lab visualization interactive freezing-point-depression cryoscopy thermodynamics

Overview

This module emphasizes the computational interpretation of noisy, time-resolved thermodynamic data through interactive visualization and numerical analysis of cooling curves. Students analyze temperature vs. time data collected during the freezing of pure solvent and solution samples with Beckmann's cryoscopic apparatus to determine the freezing point depression and calculate the molar mass of an unknown solute. Unlike traditional implementations of the experiment that rely primarily on manual inspection of cooling curves, this module introduces students to computational approaches for identifying thermodynamically meaningful transition regions in experimental datasets using numerical differentiation. Emphasis is placed on the relationship between smoothing and numerical differentiation for this module. Students compare the rolling average and Savitzky-Golay smoothing methods to examine how different approaches influence derivative behavior and identify characteristic regions within the cooling curves.

Scientific Learning Objectives

  • Explain colligative properties
  • Recognize how numerical differentiation is used to determine cooling curves
  • Determine molar mass of an unknown solute via freezing point depression

Cyberinfrastructure Learning Objectives

  • Use data slicing and booleans to find relevant information in an array
  • Plot and analyze a derivative function interactively
  • Compute the molar mass of an unknown compound using cooling curves and freezing point depression
  • Use Python functions to save time in doing repetitive tasks

Instructor Notes

Additional context for instructors using this lesson:

• The visualization exercises are very engaging • allow extra time for exploration and play.
• Part 1 can be graded largely on completion as a pre-lab assignment while Part 2 is designed as formative assessment where answers are formally graded in the lab report.
• Part 1 of this module was also used for the "Determining Heat Capacity Ratios via Experimental Data and Statistical Mechanics" module in the original implementation since students could choose which lab of the two to write the formal report.
• Screenshots of the interactive slider results are saved as Interactive_X.png where X=Tfus, mix1, or mix2 at 300 dpi. This allowed students to directly import these figures to their formal lab report.
• For this data, cyclohexane was the solvent and p-dibromobenzene was the solute added as the mixture.
• Sample data is provided to use the notebook. Any custom data should be formatted in the same way as the sample data for best compatibility.
• The instructor version works in both ChemCompute and Colab; however, the version in Colab will not render the markdown JupyterMyST colored cells.

Timing notes:
• Part 1 typically takes students 30-60 minutes.
• Part 2 can be rushed in 2 hours but is better with 3 hours.

Common student questions:
• "Why isn't this working?" • good opportunity to remind students of patience that comes with programming

Google Colab

No installation required. All dependencies are installed automatically when you run the notebooks.
