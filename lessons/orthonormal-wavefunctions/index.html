Orthonormal Wavefunctions

Students will explore orthonormality and normalization of basis sets and superposition wavefunctions.

Programming Skill: Beginner
Primary Course: Physical Chemistry
Format: Single Notebook
Authors: Prof. Heidi Hendrickson
Estimated Time: 2-3 hours
Piloted with: Undergraduate - Upper Level
Students Tested: 14
python quantum-mechanics visualization wavefunctions

Overview

In this lesson, students will calculate inner products, plot the products of wavefunctions, and interpret how coefficients and normalization constants impact the amplitude of the wavefunction. This activity reviews material students are familiar with from lecture, but often have a hard time visualizing and understanding. Students normalize a set of orthogonal functions and then use that set to create a superposition wavefunction, compare "good" and "bad" superposition wavefunctions, and normalize the "bad" wavefunction. Students visualize and interpret how coefficients and normalization constants scale the wavefunction amplitude. This activity is useful in a Physical Chemistry - Quantum course. It was piloted over two 75-minute class sessions.

Scientific Learning Objectives

  • Calculate the inner product of two functions
  • Use the inner product to determine if functions in a set are orthonormal
  • Normalize a set of orthogonal functions
  • Normalize a superposition wavefunction
  • Calculate the coefficients for a basis function in a superposition wavefunction
  • Interpret how the basis function coefficients and normalization constant scale a wavefunction

Cyberinfrastructure Learning Objectives

  • Write and execute Python code in Jupyter notebooks
  • Write user-defined functions
  • Manage floating point precision issues
  • Create plots with multiple subplots using plt.subplots()

Prerequisites

Scientific Prerequisites:

  • General chemistry
  • Basic familiarity with the state postulate of quantum mechanics
  • Basic understanding of probability distribution functions

Programming Prerequisites:

  • Basic Python syntax (variables, loops, functions)
  • Basic understanding of matplotlib.pyplot.subplots()
  • Basic familiarity with scipy.integrate.quad()
  • Basic familiarity with Lambda expressions

Instructor Notes

Additional context for instructors using this lesson:

• This lesson works well when paired with a traditional lecture on properties of wavefunctions
• Students often struggle with the concept of orthogonal functions and integration
• The plotting code is a little overwhelming for students to follow • it helps to walk them through a few lines of it
• The background information is quite extensive • it's there for review, so it's ok to skip/skim over it

Timing notes:
• The notebook was divided into two 75-minute sessions in the pilot, but it went long due to time spent on the background
• Students will ask questions about the background info throughout the session, so you can go back to it when it's relevant for them

Common student questions:
• "Why do we have to integrate the product of two functions?" • good opportunity to explain the similarity between integrals and sums (if they get the discrete dot product)
• "Does the inner product include the integral?" • good opportunity to explain how integration "gets rid of" the integration dimension
• "Why do we use Dirac notation?" • also good chance to relate discrete and continuous variables and mention the Kronecker delta
