Calorimetry: Determining Reaction Enthalpies via Analyzing Thermograms

Students will learn how to analyze calorimetry thermograms and compute reaction enthalpies.

Programming Skill: None
Primary Course: Physical Chemistry Lab
Also for: Physical Chemistry, General Chemistry
Format: Multi-Part Module
Authors: Prof. Prajay Patel
Estimated Time: 3-4 hours
Piloted with: Undergraduate - Third/Fourth Year
Students Tested: 10
python pandas physical-chemistry lab calorimetry interactive visualization thermodynamics

Overview

The notebook guides students through the analysis of experimental calorimetry data using temperature-time thermograms, emphasizing data ingestion, visualization, and model-based interpretation. Students implement multiple approaches for determining ΔT to account for heat exchange with the surroundings, enabling comparison of analytical methods and discussion of experimental assumptions. Using standard scientific Python libraries (NumPy, SciPy, Pandas, and Matplotlib), students calculate heat flow and reaction enthalpies and propagate experimental uncertainty. Embedded reflection questions and scaffolded code cells support students with little or no prior programming experience while reinforcing core thermochemistry concepts. This notebook aesthetics are designed around a solution calorimetry experiment to determine the heat of neutralization of HCl and NaOH, but any calorimetric experiment that outputs a thermogram can use this analysis notebook with custom data.

Scientific Learning Objectives

  • What physical processes might cause the temperature to drift before and after the reaction?
  • How can we fit a thermogram?
  • How do we calculate the instantaneous mixing time from our data?
  • Calculate reaction enthalpies​ using calorimetric techniques.

Cyberinfrastructure Learning Objectives

  • Perform linear and nonlinear regression fitting on experimental thermograms
  • Utilize Python functions to automate repetitive tasks
  • Perform numerical integration on experimental thermograms
  • Increased comfortability with pandas

Instructor Notes

Additional context for instructors using this lesson:

• This module applies to all forms of calorimetry that has an output of a thermogram as a figure.
• Sample data is provided to use the notebook. Any custom data should be formatted in the same way as the sample data for best compatibility.
• The aesthetics of the notebook follow a solution calorimetry experiment to determine the heat of neutralization. This notebook is intended to also work with thermograms generated with bomb calorimetry.
• The interactive components are a defining feature of this module. Allow time to explore and answer questions.
• Part 1 can be graded largely on compoetion as a pre-lab assignment while part 2 is designed as formative assessment where answers are formally graded in the lab report
• The instructor version works in both ChemCompute and Colab; however, the version in Colab will not render the markdown JupyterMyST colored cells.

Timing notes:
• Part 1 typically takes students 30-60 minutes..
• Part 2 can be rushed in 2 hours but is better with 3 hours.

Common student questions:
• "What is the point of using multiple analysis methods?" • good opportunity to discuss numerical integration and data analysis practices
• "Why isn't this working?" • good opportunity to remind students of patience that comes with programming
