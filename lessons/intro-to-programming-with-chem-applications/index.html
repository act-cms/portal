Introduction to Python with Chemical Lab Applications

Students will learn how to use the pandas to analyze experimental data in a variety of applications

Programming Skill: None
Primary Course: Foundational Module
Also for: Physical Chemistry Lab, Physical Chemistry
Format: Multi-Part Module
Authors: Prof. Prajay Patel
Estimated Time: 2-3 hours
Piloted with: Undergraduate - Third/Fourth Year
Students Tested: 10
python introduction organic-chemistry spectroscopy pandas kinetics general-chemistry

Overview

This module is designed to supplement the introduction to python foundational module. This module looks into using pandas to import data from Excel and csv files into Python for further analysis. Examples include creating calibration curves (linear regression), analysis of IR spectroscopic peaks (pandas, data filtering), and kinetics using integrated rate laws (curve fitting).

Scientific Learning Objectives

  • Construct a calibration curve using linear regression.
  • Interpret IR spectroscopic data to investigate the C=O peak.
  • Determine the reaction order of experimental kinetic data using integrated rate laws.

Cyberinfrastructure Learning Objectives

  • Import your Excel data with the pd.read_csv() or the pd.read_excel() function.
  • Construct numerous types of plots with matplotlib.
  • There is a high degree of customizability in matplotlib plots.
  • The scipy.stats.linregress() function computes best fit line parameters.
  • There are plenty of applications to use Python to model chemical data.

Instructor Notes

Additional context for instructors using this lesson:

• This module is designed to be done after the foundational module (and a break)
• Part 1 is completed prior to starting the Foundational Module(s) and Part 2 is done in lab with the foundational module
• This module can work for students who have not covered IR spectroscopy in organic chemistry as they can still do the visualization activity but skip the reflection question that covers nuances of spectroscopy. Those who have had Organic Chemistry also may not get that reflection question correct.
• The instructor version works in both ChemCompute and Colab; however, the version in Colab will not render the markdown JupyterMyST colored cells.

Timing notes:
• Part 1 typically takes students 30-60 minutes.
• Part 2 can be rushed in 2 hours but is better with 3 hours.

Common student questions:
• "Why isn't this working?" • good opportunity to remind students of patience that comes with programming

Platform Requirements

ChemCompute (Recommended)

This module is compatible with ChemCompute - a specialized platform for computational chemistry education.

  • Access using your institution account
  • Pre-configured chemistry software environment
  • No personal setup required
  • Includes computational molecular science packages (Psi4, OpenMM)

Google Colab

No installation required. All dependencies are installed automatically when you run the notebooks.

  • Runs entirely in your web browser
  • Free Google account required
  • All required packages installed inline
  • Works on any device with internet
  • GPU acceleration available for computational tasks

Local Installation

For advanced users who prefer local development environments.

  • Requires conda package manager
  • Environment setup via provided environment.yml file
  • Full control over computing environment
  • Works offline once dependencies are installed
  • Can customize package versions and configurations
